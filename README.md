# Java Bank System

A simple starter Java project for basic banking system operations.  
This project was created to practice Java fundamentals and object-oriented programming concepts in a console-based application.

---

## Features

- User login system
- Balance display
- Deposit money
- Withdraw money
- Input validation
- Simple in-memory database structure
- Console-based interface

---

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
